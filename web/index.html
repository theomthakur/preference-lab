BEHIND THE NUMBERS / 04

A little lab, not a leaderboard.

Built to learn how post-training and evaluation fit together, with the limitations left visible.

01

Generate scenarios

A rule-based oracle creates synthetic returns cases and reference decisions. The preference labels are synthetic, not human judgments.

02

Train small models

Supervised examples, preference pairs and verifier rewards produce SFT, DPO and GRPO variants of a 0.5B model.

03

Evaluate together

Frozen models answer the same held-out cases. The checker requires the right action and exact evidence; comparisons are paired.

WHAT THIS DOESN’T SHOW

Small by design.
Honest by default.

One model family and one training seed, using synthetic data and an exact-match rule checker. Tool use was explored separately: base and SFT each scored 0/20 on validation cases after the protocol fix. This is not a production system, human preference study, or evidence of frontier-scale performance.
