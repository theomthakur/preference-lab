    02

    The evaluation contract

    Every score has a specific meaning and a boundary.

    What goes in

    A fictional policy and ticket, rendered with line IDs. The model returns an action and evidence IDs.

    What counts

    A strict pass needs the correct action and exactly the required evidence IDs. Action and evidence accuracy are reported separately.

    How to read it

    Examples in the same case group are related; intervals use a group bootstrap. One seed leaves training variance unmeasured.

    Where it stops

    Labels are synthetic. The new test uses the same generator and cannot establish production or real-world performance.

    Artifacts
    Code, synthetic cases, predictions and metrics are in GitHub. Adapter weights are stored separately.
    04

    Failure modes and next steps

    These results are a starting point for a better experiment.

    Evidence errors

    On the new test, action accuracy was 84.25%, but exact evidence was 50%. Inspect missing, extra and incorrect citations separately.

    Wording sensitivity

    Strict accuracy was 59.5% on familiar wording and 37% on held-out wording. Test more varied phrasing in a future study.

    Tool-use boundary

    The original base and SFT models scored 0/20 on the tool-environment validation cases. Trained tool use was not achieved.

    Next evaluation

    Develop changes using training and validation data, freeze the candidate, then use another unseen test. The current test has been inspected.
