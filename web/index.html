SEPARATE TRACK

Tool environment: The base and SFT models were also tested on 20 validation cases requiring tool calls. Both scored 0/20. Trained tool use was not achieved.

WHY A RULE ORACLE?

It gives a repeatable reference answer, but the synthetic task reflects the assumptions in its rules.

WHY PAIRED EVALUATION?

Every model sees the same cases, so we can compare their answers case by case.

WHAT REMAINS UNCERTAIN?

One seed, a small model, and synthetic data limit generalization. The trained weights are not in GitHub.
